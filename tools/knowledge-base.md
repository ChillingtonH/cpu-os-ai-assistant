# 知识库配置（CPU/OS 底层领域）

## 方案选择
- **最小方案**：直接读取本地文件夹（零配置、免费，适合小规模资料）——先用这个
- **完整方案**：RAG 知识库（向量化 + 语义搜索，适合大规模资料）——资料多了再升级

## 本地文件夹方案

### 目录结构
```text
docs/sources/
├── riscv-unprivileged.pdf   ← RISC-V 非特权规范
├── riscv-privileged.pdf     ← RISC-V 特权规范
├── csapp-notes.md           ← CSAPP 笔记
└── ...                      ← 其他权威资料
```
（首次使用时创建 `docs/sources/` 文件夹）

### 使用方法
1. 把权威资料放入 `docs/sources/`（支持 .md / .txt / .pdf）
2. 教学、调研、评审时，读取这些文件作为本地权威来源
3. 优先本地资料 + 权威来源白名单，其次才是网络搜索

### 检索方式
- 按文件名匹配：知道资料名直接读
- 按关键词搜索：在文件内容里搜关键词
- 手动指定：问题里指明"参考 docs/sources/xxx.pdf"

### 局限性
- 不支持语义搜索（只能关键词匹配，不能理解"意思相近"）
- 资料超过约 20 篇时效率下降
- 需要手动维护

## 升级到完整 RAG（资料多了再做）
1. 资料接入：自动监控文件夹变化
2. 文档切块：按段落/语义切块
3. 向量化：用 Embedding 模型生成向量
4. 检索：语义搜索返回最相关的内容块
