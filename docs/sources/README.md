# 知识库资料清单（docs/sources）

## 说明
- 这里放权威资料（.md / .txt / .pdf），供助手的教学、调研、评审读取。
- 资料必须权威：官方规范、权威教材、顶会论文、厂商手册。不用来源不明的博客/论坛/问答。
- 放好后告诉我，我帮你同步到已装的 skill。

## 经典著作推荐清单

### 打基础（全景入门）
1. **《深入理解计算机系统》（CSAPP）** — Bryant & O'Hallaron
   - 覆盖：计算机系统全景（硬件 + 操作系统 + 编译器），从程序员视角看底层
   - 用途：概念教学打基础
   - 获取：正版教材 / 学校图书馆

### CPU / 体系结构方向
2. **《计算机组成与设计：硬件/软件接口》** — Patterson & Hennessy
   - 覆盖：CPU 设计、指令集、流水线、存储层次
   - 用途：项目导师（做 CPU 项目）
   - 获取：正版教材 / 学校图书馆

3. **《计算机体系结构：量化研究方法》** — Hennessy & Patterson
   - 覆盖：高级体系结构（缓存、流水线、多核、内存层次）
   - 用途：进阶学习、评审优化
   - 获取：正版教材 / 学校图书馆

### 操作系统方向
4. **《操作系统概念》** — Silberschatz, Galvin, Gagne（俗称"恐龙书"）
   - 覆盖：进程、内存、文件系统、调度
   - 用途：操作系统方向教学 / 项目
   - 获取：正版教材 / 学校图书馆

5. **《现代操作系统》** — Andrew Tanenbaum
   - 覆盖：操作系统原理与实现
   - 用途：操作系统方向教学 / 项目
   - 获取：正版教材 / 学校图书馆

### 官方规范（免费，可立即获取）
6. **RISC-V 指令集手册（Vol.1 非特权架构 / Vol.2 特权架构）**
   - 官方免费 PDF，在官网 riscv.org 的 Specifications 页面下载
   - 用途：RISC-V 相关项目、调研的权威依据（最高权威级别）
